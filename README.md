# سامانه مدیریت IT فرودگاه

رابط کاربری استاتیک، فارسی و راست‌چین برای مدیریت فناوری اطلاعات فرودگاه. این نسخه شامل داشبورد مدیریتی و صفحات تجهیزات و دارایی‌ها، پرسنل، شبکه و رک‌ها، تلفن و VoIP، نرم‌افزارها و سامانه‌ها، گزارش‌ها و تنظیمات است.

## اجرا
فایل `index.html` را در مرورگر باز کنید یا پروژه را با Live Server اجرا کنید. نیازی به نصب پکیج یا اجرای backend نیست.

## ساختار
- `index.html` — چارچوب برنامه، منوی کناری و ناحیه محتوای صفحات
- `styles.css` — طراحی واکنش‌گرا، راست‌چین و اجزای رابط کاربری
- `app.js` — رندر صفحات، داده‌های نمونه، جست‌وجو و فیلترها

فونت Vazirmatn از Google Fonts بارگذاری می‌شود و در صورت نبود اینترنت، فونت جایگزین سیستم استفاده می‌شود.

## نکته
این پروژه نمونه فرانت‌اند است. اطلاعات تجهیزات و پرسنل داده‌های نمایشی هستند و به پایگاه داده یا API متصل نیستند.
