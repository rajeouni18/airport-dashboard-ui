# داشبورد مدیریت IT فرودگاه

رابط کاربری استاتیک، فارسی و راست‌چین برای داشبورد مدیریت فناوری اطلاعات فرودگاه. طراحی صفحه بر اساس تصویر مرجع `assets/design-reference.png` پیاده‌سازی شده است.

## اجرا
1. فایل ZIP را استخراج کنید.
2. فایل `index.html` را در مرورگر باز کنید.
3. برای توسعه راحت‌تر، پوشه را با Live Server اجرا کنید.

نیازی به نصب پکیج یا اجرای سرور نیست. فونت Vazirmatn از Google Fonts بارگذاری می‌شود؛ بدون اینترنت از فونت جایگزین سیستم استفاده می‌شود.

## ساختار
- `index.html` — ساختار و محتوای صفحه (نوار کناری، هدر، بنر، کارت‌های آماری، نمودارها، فعالیت‌ها، جدول تجهیزات)
- `styles.css` — طراحی واکنش‌گرا، پالت رنگ و شبکه‌بندی (Grid) صفحه
- `app.js` — منوی موبایل، جست‌وجوی فعالیت‌ها و اعلان‌های نمایشی
- `assets/design-reference.png` — تصویر مرجع طراحی
- `assets/hero.jpg` — تصویر پس‌زمینه بنر
- `assets/avatar.jpg` — تصویر کاربر در هدر
- `assets/airport.jpg` — تصویر کارت اطلاعات فرودگاه

## نکته مهم
آمار، نمودار و فعالیت‌ها نمونه هستند و به API یا پایگاه داده متصل نیستند. پیوندهای بخش‌های مدیریتی هم در این نسخه نمایشی هستند. برای سامانه واقعی، باید رابط را به backend متصل کنید.
